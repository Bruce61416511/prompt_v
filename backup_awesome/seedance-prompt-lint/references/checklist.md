## 一、运镜词表

### 基础运镜（可直接写）

| 类别 | 术语 |
|---|---|
| **推拉** | 推镜头、缓慢推进、快速推近、拉镜头、缓慢拉出、后拉 |
| **摇移** | 摇镜头、左摇、右摇、横移、平移、移镜头 |
| **跟拍** | 跟拍、跟随镜头、跟踪、同速水平移动 |
| **环绕** | 环绕拍摄、环绕半圈、以主体为中心环绕 |
| **升降** | 升镜头、降镜头、升降镜头 |
| **固定** | 固定镜头、机位固定、镜头静止 |
| **手持** | 手持跟拍、轻微手持感、手持晃动 |

### 高级运镜（官方 7 种，必填字段）

| Step | 运镜 | 必填字段 | 范例 |
|---|---|---|---|
| 1 | **一镜到底** | 连续经过的主体 + 空间 + 事件顺序 | 镜头从咖啡馆门口一路跟随主角穿过吧台、过道，最后停在二楼窗前 |
| 2 | **希区柯克变焦** | 主体保持的大小 + 背景被拉近/推远 | 主体面部始终保持原大，背后走廊空间被缓慢拉近 |
| 3 | **航拍视角** | 俯视高度 + 移动方向 + 环境范围 | 镜头从山顶 200 米高度沿山脊向北推进，覆盖整片森林 |
| 4 | **FPV** | 第一人称路径 + 速度 + 转向 | FPV 镜头从地铁站入口高速冲入，连续穿越闸机、扶梯、月台 |
| 5 | **子弹时间** | 被冻结的动作 + 环绕方向 | 子弹出膛瞬间被冻结，镜头以 360° 弧线环绕主体 |
| 6 | **手持镜头** | 跟拍对象 + 晃动程度 | 镜头紧跟记者穿过人群，轻微晃动模拟奔跑节奏 |
| 7 | **回弹变速** | 加减速/回弹节点 + 最终停留状态 | 滑板在第 3 秒突然减速回弹，最后停在画面左侧 |

### ⚠️ 自造词黑名单（查到即报）

`电影感运镜` `高级运镜` `炫酷镜头` `大片质感运镜` `好看的镜头` `很有质感的运镜`

→ 这些词模型无法执行，必须替换为具体术语。

## 七、逐段检查表（每段都要过一遍）

复制这张表，每个时间段填一遍：

| 要素 | 要求 | 本段是否满足 |
|---|---|---|
| **时间** | 明确区间，如 `0-6秒` | ☐ |
| **景别** | 至少一个景别词 | ☐ |
| **运镜** | 说清"从哪到哪 + 怎么动" | ☐ |
| **画面内容** | 主体 + 环境 + 光线，具体可观察 | ☐ |
| **动作** | **必须是"从 A 到 B 的变化过程"** | ☐ |
| **结束状态** | （长视频）本段结束时的可见状态 | ☐ |

**五项缺任一项 → 该段报问题。**

## 八、常见病症速查（语义层重点）

| 病症 | 原文示例 | 改法 |
|---|---|---|
| **静态当动作** | 水珠凝结在瓶身 | 水珠沿瓶身缓缓滑落，留下一小片湿痕 |
| **模糊当动作** | 雾气升腾 | 雾气从瓶口逸出，逐渐在侧逆光中散开 |
| **无动作** | 产品定格在画面中央 | 光线从产品两侧向顶部收拢，画面静止两秒后结束 |
| **运镜只说位置** | 镜头回到产品特写 | 镜头以中景近景缓慢推入产品特写 |
| **运镜无客体** | 环绕拍摄 | 镜头以产品为中心顺时针环绕半圈，产品始终居中 |
| **空词堆砌** | 画面非常高级、极具电影感 | 换成：奶油白与浅青绿主色，侧逆光勾勒轮廓，浅景深虚化背景 |
| **情绪直给** | 她感到很开心 | 她眉眼舒展，嘴角浮现轻微笑意，肩膀随之放松 |
| **事件过密** | 一段里同时发生开门、换鞋、倒水、坐下 | 拆成 4 段，每段一个主要变化 |
| **概述缺要素** | 写实商业广告风格，色调柔和 | 一罐 X 饮品在影棚的产品展示，过渡到清晨厨房的真实饮用场景（主体+地点+事件+风格） |
| **违规表述** | 调理肠胃、改善便秘 | 改为意象化表达（如"有益菌群温和抵达"），且画面不出现功效文字 |

## 九、参数对照（用于查过期数字）

| 项 | 2.0（过期） | **2.5（正确）** |
|---|---|---|
| 单次时长 | 4-15 秒 | **4-30 秒** |
| 参考图片 | ≤9 张 | **≤30 张** |
| 参考视频 | ≤3 个，总 ≤15s | **≤10 个，总 ≤30s** |
| 参考音频 | ≤3 段，总 ≤15s | **≤10 段，总 ≤30s** |
| 素材总数 | ≤12 个 | **≤50 个** |
| 超长视频 | 无 | **30-180 秒一次性直出** |
| 输出分辨率 | 480p/720p | **480p/720p（未变，网传 4K 未获官方确认）** |

## 十、质检结论速判

跑完三层后，按下表给结论：

| 情况 | 结论 |
|---|---|
| 有 ❌ 必改项 | **不能交付**，改完再给用户 |
| 只有 ⚠️ 提醒 | **可以交付**，但必须把提醒一并告知用户 |
| 全部 ✅ | 正常交付 |

**记住：语义层结果一律算 ⚠️，不做否决。最终由人定夺。**
