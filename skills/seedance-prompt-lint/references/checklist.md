# 质检词表与逐段检查表

> 配套 `seedance-prompt-lint` 使用。词表来自即梦官方手册 §十一 + 实战补充 + goodcase 案例常用写法。
>
> **本表已按 v2.0.0 改造**：每条词表都补了英文大写写法。本仓场景技能走 goodcase 方言，
> 机位术语习惯中英混写（段头括号里 `Ground-level Low Angle`，正文用中文），
> 只认中文词表会把合法的英文写法误判成缺失。

## 一、运镜词表

### 基础运镜（可直接写）

| 类别 | 中文 | 英文（同样算数） |
|---|---|---|
| **推拉** | 推镜头、缓慢推进、快速推近、拉镜头、缓慢拉出、后拉 | `Push in` / `Push-in` / `Dolly in` / `Pull out` / `Pull back` / `Dolly out` / `Zoom in` / `Zoom out` |
| **摇移** | 摇镜头、左摇、右摇、横移、平移、移镜头 | `Pan` / `Pan left` / `Pan right` / `Tilt up` / `Tilt down` / `Truck` / `Whip pan` |
| **跟拍** | 跟拍、跟随镜头、跟踪、同速水平移动 | `Tracking` / `Follow` / `Dynamic Tracking` / `Side Tracking` / `Car-to-car` |
| **环绕** | 环绕拍摄、环绕半圈、以主体为中心环绕 | `Orbit` / `Arc` / `360 orbit` / `Circle around` |
| **升降** | 升镜头、降镜头、升降镜头 | `Crane up` / `Crane down` / `Jib` / `Boom` |
| **固定** | 固定镜头、机位固定、镜头静止 | `Static` / `Locked-off` / `Lock-off` / `Static frame` / `Fixed frame` / `Locked camera` |
| **手持** | 手持跟拍、轻微手持感、手持晃动 | `Handheld` / `Handheld shake` / `Slight handheld` |
| **机位视角** | 第一人称视角、主观视角、过肩视角、低角度、俯拍、仰拍、鸟瞰 | `POV` / `First-person` / `Handlebar POV` / `Ground-level Low Angle` / `High Angle` / `Low Angle` / `Overhead` / `Bird's-eye` / `Top-down` |
| **焦距** | 变焦、跟焦、拉焦 | `Rack focus` / `Follow focus` / `Focus pull` |

> ⚠️ **"固定镜头"也是运镜**，必须逐段写出来。某段写"机位固定不动"但没写进每段 → 该段仍需补一句
> `camera locked, static frame throughout`，否则模型可能自行加运动。

### 高级运镜（官方 7 种，必填字段）

| Step | 运镜 | 必填字段 | 范例 |
|---|---|---|---|
| 1 | **一镜到底** | 连续经过的主体 + 空间 + 事件顺序 | 镜头从咖啡馆门口一路跟随主角穿过吧台、过道，最后停在二楼窗前 |
| 2 | **希区柯克变焦** | 主体保持的大小 + 背景被拉近/推远 | 主体面部始终保持原大，背后走廊空间被缓慢拉近 |
| 3 | **航拍视角** | 俯视高度 + 移动方向 + 环境范围 | 镜头从山顶 200 米高度沿山脊向北推进，覆盖整片森林 |
| 4 | **FPV** | 第一人称路径 + 速度 + 转向 | FPV 镜头从地铁站入口高速冲入，连续穿越闸机、扶梯、月台 |
| 5 | **子弹时间** | 被冻结的动作 + 环绕方向 | 子弹出膛瞬间被冻结，镜头以 360° 弧线环绕主体 |
| 6 | **手持镜头** | 跟拍对象 + 晃动程度 | 镜头紧跟记者穿过人群，轻微晃动模拟奔跑节奏 |
| 7 | **回弹变速** | 加减速/回弹节点 + 最终停留状态 | 滑板在第 3 秒突然减速回弹，最后停在画面左侧 |

### ⚠️ 自造词黑名单（查到即报）

`电影感运镜` `高级运镜` `炫酷镜头` `大片质感运镜` `好看的镜头` `很有质感的运镜`
`cinematic camera` `cool shot` `epic cinematography`

→ 这些词模型无法执行，必须替换为具体术语。
→ **例外**：`Ground-level Low Angle` 这类**具体**的英文机位原词是合法写法，不算自造词。

## 二、景别词表

```
大远景 → 远景 → 全景 → 中景 → 近景 → 特写 → 大特写
```

| 中文 | 英文（同样算数） |
|---|---|
| 大远景 / 远景 | `EXTREME WIDE` / `EWS` / `WIDE` / `WS` / `Long shot` |
| 全景 | `FULL SHOT` / `FS` / `Wide full shot` |
| 中景 | `MEDIUM SHOT` / `MS` |
| 中近景 / 半身景 | `MEDIUM CLOSE-UP` / `MCU` / `Half shot` |
| 近景 | `CLOSE SHOT` |
| 特写 | `CLOSE-UP` / `CU` |
| 大特写 / 微距 | `EXTREME CLOSE-UP` / `ECU` / `MACRO` |
| 补充 | 俯视全景、中景低机位 |

**检查要点**：

- 整条提示词**从头到尾只有一个景别** → 报 ⚠️ 提醒（节奏单调）
- 整条提示词**从头到尾没有任何景别** → 报 ❌ 必改（这是硬伤，模型不知道该怎么取景）

## 五、禁止项词表（反向描述）

**必须出现至少一项**（缺失即报 ❌）：

```
无字幕 / 不要字幕 / 不出现字幕 / 无对白 / 无旁白
无 BGM / 无背景音乐 / 不要背景音乐 / 无音乐
无水印 / 无 logo / 无文字 / 无文字叠加 / 无贴纸
禁止生成多余台词 / 禁止换脸 / 禁止变形 / 禁止穿模
禁止新增无关人物 / 动物 / 道具
不出现慢动作 / 不出现卡顿感
```

英文：`No subtitles` / `No on-screen text` / `No watermark` / `No logo` / `No BGM` / `No added dialogue` / `No extra characters`

> **goodcase 方言**：反向描述写成独立的「全局约束 / NEGATIVE」块即可，
> **不要求**开头声明 + 结尾重申各写一遍（那是官方格式的建议，属 B 类）。

## 六、声音符号（官方 5 种）

| 用途 | 符号 | 示例 |
|---|---|---|
| 音乐 | `· · ·` | `·(背景播放舒缓钢琴乐)·` |
| 音效 | `< >` | `<远处传来钟声>` |
| 台词 | `{ }` | `{你好，欢迎回来}` |
| 字幕 | `【 】` | `【第一章：启程】` |

**禁用写法**（查到即报 ⚠️，但**属 B 类格式备注**）：

```
无背景音乐，只保留人物对白、环境声和动作音效。   ← 若走官方格式，应用符号表达
不要字幕。
不要任何声音。
```

> **goodcase 方言**：音效写成 `音效：电机启动的低鸣、轮胎压水的沙沙声` 是**合法**的，
> 不要报成问题。只有当用户明确要走官方符号体系时，才在「📐 格式备注」里提一句。

## 七、逐段检查表（每段都要过一遍）

复制这张表，每个时间段填一遍：

| 要素 | 要求 | 本段是否满足 |
|---|---|---|
| **时间** | 明确区间，如 `0-6秒` / `[00:00-00:04]`，且与上一段首尾相接 | ☐ |
| **景别** | 至少一个景别词（中/英均可） | ☐ |
| **运镜** | 说清"从哪到哪 + 怎么动"（固定镜头也要写） | ☐ |
| **画面内容** | 主体 + 环境 + 光线，具体可观察 | ☐ |
| **动作** | **必须是"从 A 到 B 的变化过程"** | ☐ |
| **结束状态** | （长视频）本段结束时的可见状态 | ☐ |

**五项缺任一项 → 该段报问题。**

## 八、常见病症速查（语义层重点，A 类）

| 病症 | 原文示例 | 改法 |
|---|---|---|
| **静态当动作** | 水珠凝结在瓶身 | 水珠沿瓶身缓缓滑落，留下一小片湿痕 |
| **模糊当动作** | 雾气升腾 | 雾气从瓶口逸出，逐渐在侧逆光中散开 |
| **无动作** | 产品定格在画面中央 | 光线从产品两侧向顶部收拢，画面静止两秒后结束 |
| **运镜只说位置** | 镜头回到产品特写 | 镜头以中景缓慢推入产品特写 |
| **运镜无客体** | 环绕拍摄 | 镜头以产品为中心顺时针环绕半圈，产品始终居中 |
| **空词堆砌** | 画面非常高级、极具电影感 | 换成：奶油白与浅青绿主色，侧逆光勾勒轮廓，浅景深虚化背景 |
| **情绪直给** | 她感到很开心 | 她眉眼舒展，嘴角浮现轻微笑意，肩膀随之放松 |
| **事件过密** | 一段里同时发生开门、换鞋、倒水、坐下 | 拆成 4 段，每段一个主要变化 |
| **概述缺要素** | 写实商业广告风格，色调柔和 | （仅官方方言）一罐 X 饮品在影棚的产品展示，过渡到清晨厨房的真实饮用场景 |
| **违规表述** | 调理肠胃、改善便秘 | 改为意象化表达（如"有益菌群温和抵达"），且画面不出现功效文字 |
| **运镜与动作打架** | 同段写"镜头拉远"+"人物驶出画面"+"人与车缩到画面下三分之一" | 三者空间互斥：驶出画面就不该还在画面里。二选一 |
| **时间段断档** | `0-3秒` → `4-7秒` → `8-11秒` | 中间各空 1 秒，模型不知道那 3 秒生成什么。改为 `0-3` / `3-6` / `6-9` / `9-12` |

## 十、方言速查（v2.0.0 新增）

| 特征 | goodcase 方言 | 即梦官方方言 |
|---|---|---|
| 判据 | 只有分块结构 + 时间轴，无概述句、无 `@图片N` | 有 `【一句话概述】` 或 `@图片N` |
| 代表技能 | 本仓 27 条 `seedance-*` 场景技能 | `seedance-prompt-library` + 官方手册 |
| 四段式 | ❌ 不要求 | ✅ 必须 |
| 声音符号 | ❌ 不要求（自然语言即可） | ✅ 必须用 `· < { 【` |
| 禁止项双写 | ❌ 不要求（放结尾一块即可） | ✅ 开头 + 结尾各一遍 |
| 机位术语 | 中英混写，英文原词写括号里 | 中文官方词表 |

**判错方言 = 全盘误报。** 不确定就问用户一句，或者按"没有概述句/没有 @引用 → goodcase 方言"处理。

## 十一、质检结论速判

跑完 A / B 两类后，按下表给结论：

| 情况 | 结论 |
|---|---|
| A 类有 ❌ 必改项 | **不能交付**，改完再给用户 |
| A 类只有 ⚠️ 提醒 | **可以交付**，但必须把提醒一并告知用户 |
| A 类全 ✅，B 类有备注 | **可以交付**。B 类只作参考，放「📐 格式备注」栏即可 |
| 全 ✅ | 正常交付 |

**记住：A 类语义层结果一律算 ⚠️，不做否决。B 类一律不算必改。最终由人定夺。**
