## 一、改了哪些东西

## 二、改造前后的实测对比

同一批产物（3 份 output）、同一个模型（deepseek-chat）、temperature 0.2。

### 结论栏对比

| 产物 | v1.0.0 | **v2.0.0** |
|---|---|---|
| `时间轴分镜-雨夜骑手-15秒.md` | ❌3 ⚠️6 ✅12 | ❌1~2 ⚠️4 ✅12 |
| `随机抽测-定格动画.md` | ❌5 ⚠️4 ✅6 | ❌3 ⚠️4 ✅6 |
| `可口可乐-街头分享-15秒竖屏.md` | ❌4 ⚠️5 ✅6 | ❌2~3 ⚠️4 ✅6~8 |

### 必改项的成分变化

**v1.0.0 报的 12 项「必改」**：

| 类型 | 数量 | 明细 |
|---|---|---|
| 真问题 | 8 | 时间段断档 3 秒 / 全片无时间戳 / 全片无景别 / 5 段无逐段运镜 / 整条无声音层 / 单段 5 事件 / 运镜与动作互斥 ×2 |
| **格式误报** | 3 | 缺【一句话概述】3/3（goodcase 路线不要求）、声音未用 `< >` 2/3 |
| 字面主义 | 1 | 抠「固定机位」四个字里没有「固定镜头」 |

**v2.0.0 报的必改项**（任一次运行）：

| 类型 | 数量 | 明细 |
|---|---|---|
| 真问题 | **全部** | 运镜与动作空间互斥 / 全片无时间戳 / 全片无景别 / 时间段断档 / 单段事件过密 |
| 格式误报 | **0** | 全部进了「📐 格式备注」栏，或整栏不适用 |

### 具体样例：可口可乐那条的「必改 1」

改造前后都是同一项，说明这个硬伤抓得稳：

> **1. 时间段断档，每段之间空 1 秒**
> - 位置：全篇四段
> - 问题：`0-3秒` → `4-7秒` → `8-11秒` → `12-15秒`。段间出现 `3-4秒`、`7-8秒`、`11-12秒` 三处空档，模型无法判断这三秒该生成什么。
> - 建议改为：`0-3秒` / `3-7秒` / `7-11秒` / `11-15秒`

## 三、改造后的选中行为（实测）

26 项挑技能测试：**26/26 全对，0 次多选**。

| 需求写法 | 实际选中 |
|---|---|
| 帮我写一条 15 秒产品广告提示词 | `seedance-product-commercial-shotlist` |
| 帮我写一条 15 秒产品广告提示词，**写完直接给我一条能用的成稿** | `seedance-product-commercial-shotlist` |
| 写一条美食 ASMR 提示词，**写完顺便帮我检查一下有没有问题** | `seedance-food-asmr` + `seedance-prompt-lint` |
| 写一条分镜提示词，**别把没查过的稿子交给我** | `seedance-timeline-shot-script` + `seedance-prompt-lint` |
| 帮我写个宠物短视频提示词，**我现在就要用，确认没问题再发我** | `seedance-pet-animal` + `seedance-prompt-lint` |
| 帮我质检一下这段提示词：一个男人在雨里跑步 | `seedance-prompt-lint` |
| 这条提示词帮我挑挑错：0-3秒他站起来，4-7秒他走过去 | `seedance-prompt-lint` |

**行为总结**：

- 单纯"写一条 XX 提示词"→ **不带 lint**（不多花字符、不多跑一次）
- 说了「要成稿 / 顺便检查 / 确认没问题 / 别交没查过的」→ **自动带上 lint**，生成完立刻质检
- 明确要求质检 → **只选 lint**，不夹带任何生成技能

### 上下文成本（实测）

| 项 | 改造前 | 改造后 |
|---|---|---|
| 技能数 | 29 | 31 |
| 挑技能清单（每次必发） | 13,541 字符 | **14,052 字符**（≈ 4,918 tokens，+511 字符） |
| 选中 lint 时的额外注入 | — | SKILL.md 正文 5,351 + `checklist.md` 6,017 = **11,408 字符 ≈ 4,000 tokens** |

**只在需要质检时才付这 4,000 tokens。** 单纯"写一条提示词"不带 lint，成本不变。

## 四、已知局限

1. **LLM 当裁判有波动。** 同一份稿子跑两次，必改项数可能从 3 变 2。观察到的具体例子：某次把**有** `NEGATIVE` 块的定格动画稿误报成「无反向描述块（S5）」。
   → 定位是「第二双眼睛」，不是确定性校验器。**报告里的每一条都值得看一眼，但也允许人工否掉。**
2. **S11 声音层是"提醒"级**，不是必改。判定"这片型是否以声音为主要质感"本身是主观的。
3. **B 类并没删掉，只是降级。** 如果哪天要按即梦官方格式出稿，那栏还是有用的。
4. `seedance-storyboard-writer` 只是拷进来补齐能力，**尚未实测**它在挑选环节的表现。
